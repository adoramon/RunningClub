# 东成西就 v1.4.0：管理员代成员上传

界面补丁 v1.4.1：跑量管理页增加紧凑待办概览；页头右侧提供代传选人入口，成员卡片姓名右侧提供代传快捷入口，底部统一放置请假与缴费确认操作。

## 新增能力

- 管理员审核页的上月未提交成员卡片增加“帮该成员上传跑量”。
- 页面上方可选择成员代传或继续当前管理员的代传草稿。
- 支持已认领及尚未认领的历史成员，跑量始终归属被代传成员。
- 上传页显示代传成员和月份，沿用多图 OCR、判断、核对及提交审核流程。
- 审核队列标注管理员代传及操作人，任一管理员通过后进入正式统计。
- 月度激励评价依据被代传成员的数据生成并持久化。

## 数据与权限

仅两个既定管理员可代传，云函数逐次校验权限。已有待审核、已通过、历史跑量或已结算月份不可覆盖。未注册成员无需创建虚假账号，认领后继续使用原代传记录。公积金到账仍需管理员单独确认。

## 部署与验收

需更新四个云函数：`ocr_activity_screenshot`、`submit_activity_screenshot`、`generate_monthly_evaluation`、`review_activity_submissions`；使用既有模型环境变量和 60 秒超时，无需新增密钥或集合。

真机路径：管理员首页 → 审核管理 → 上月尚未提交成员 → 帮该成员上传跑量 → 选择截图 → 识别核对 → 提交审核 → 返回审核队列通过。

本地自动化覆盖普通成员越权、审核体验账号越权、已注册和未注册成员归属、认领后记录衔接、防覆盖和共用逻辑一致性。真实成员上传和确认需由实际操作者完成。
