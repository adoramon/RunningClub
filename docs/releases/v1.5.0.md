# 东成西就 v1.5.0：个人跑量分析焕新

v1.5.2 视觉修订：根据反馈恢复战报原字号，累计卡片采用标签左对齐、数值右对齐，删除底部装饰文案并压缩内边距与高度。此方案替代 v1.5.1 的放大数字方案。

v1.5.1 视觉补丁：放大上月实际跑量、达成率、历史参考数据及累计卡片数字，收紧累计卡片内边距；较长数值分档缩小，保留单位和单行显示空间。

- 顶部个人战报突出上月实际跑量、承诺及达成率，头像、昵称和艺名集中展示。
- 最近承诺、历史月均和历史最高作为辅助数据；累计跑量与公积金使用深绿、浅暖色区分。
- 月度评价采用淡绿色卡片，并展示评价所属月份。
- 最近两年趋势加入真实月度承诺虚线，支持点击查看月份的跑量、承诺及状态。缺失与请假用空心标记区别于实际零跑量。
- 年历默认展开最近一年，较早年份折叠并显示全年累计；点击月份打开详情层查看数据和审核来源。
- 修复未达标但没有缴费记录的月份误标为“已缴基金”的问题。
