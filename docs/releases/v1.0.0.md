# 东成西就 v1.0.0 发布说明

发布日期：2026-08-05  
发布类型：微信小程序体验版

## 版本定位

`v1.0.0` 是东成西就跑团的首个可供成员体验的版本，聚焦于“封闭成员身份认领、长期历史数据保存与历史跑量分析”。

## 已实现能力

- 封闭准入：用户须填写微信昵称、选择微信头像，并认领一个未被占用的历史艺名；艺名与微信 OpenID 一次性绑定，非历史成员不能进入看板。
- 历史数据看板：展示上一个完整月的全队实际跑量、总承诺、已承诺/已提交人数、公积金余额和上月新增公积金。
- 上月达成目标排名：按完成率、再按实际跑量排序；已认领成员显示微信昵称与头像，未认领成员显示历史艺名和未注册标识。
- 跑团累计统计：展示累计跑量、运营时长及绕赤道、城市往返等动态对比。
- 个人跑量分析：可从排名进入任意成员的分析页，查看最近承诺、历史月均、历史最高、累计跑量、累计公积金贡献。
- 两年趋势与历史年历：展示最近两年的月跑量趋势，以及按年份、每行四个月排列的历史跑量年历；年历按达成目标、已缴基金、提前请假区分状态并显示完成率。
- 历史规则：历史“收/交 XX 元”记录会按连续未达标规则倒算实际跑量；历史原始记录仍保留在云端，便于长期追溯。

## 暂未开放

- 正式的运动截图云存储、管理员审核与跑量入账；当前界面中的提交入口不应作为正式月度申报使用。
- 正式月度承诺锁定、月度结算、公积金流水确认和连续未达标的自动结算。
- 面向所有微信用户的公开注册；该版本仅供历史跑团成员体验。

## 体验建议

1. 由管理员在微信公众平台把体验者加入体验成员。
2. 体验者从体验版入口进入后，完成微信昵称、头像与历史艺名认领。
3. 重点验证个人能否正确匹配并认领艺名，以及看板、排名和个人历史分析是否与历史数据一致。
4. 如发现艺名、跑量或公积金数据异常，请记录艺名和月份后反馈管理员；不要直接修改云端历史记录。
