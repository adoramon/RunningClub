# 东成西就 v1.2.0 发布说明

## 版本定位

这是面向微信审核和跑团体验的阶段性候选版。正式成员通过历史艺名认领进入；审核员使用隔离演示入口，不接触真实成员数据。

## 本版能力

- 封闭成员认领、微信昵称与头像展示。
- 上月团队看板、成员达成排名、个人历史跑量分析和月度评价。
- 上月运动截图上传、视觉识别、成员确认、管理员复核、作废与重传。
- 上月未提交/未达标成员的请假和公积金确认流程。
- 公积金收支公示、历史总账月度宫格和管理员用途化提取。
- 小程序内隐私政策与审核员隔离体验入口。

## 审核体验路径

1. 打开小程序，进入注册页。
2. 点击“微信审核员体验入口”。
3. 授权昵称和头像，输入本次审核专用的临时审核码。
4. 查看演示看板、成员分析、截图提交演示和管理员审核演示。

审核码仅在云函数环境变量中配置；不要写入源码、版本说明或公开备注。审核结束后由管理员更换或清空。

## 审核重点

- 昵称、头像、相册选择和图片上传均有用户主动触发与隐私政策说明。
- 截图仅在用户主动提交时写入 CloudBase；识别结果需要用户确认、管理员审核后才影响结算。
- 审核演示数据固定且隔离，无法访问真实跑团成员、跑量、截图或资金流水。
- 公积金提取仅两个预设管理员可发起，服务端校验用途、金额和余额。

## 发布前核对

- 微信公众平台已配置服务类目和用户隐私保护指引。
- `RUNNING_CLUB_REVIEW_ACCESS_CODE`、AI 接口地址和密钥仅存在云函数环境变量。
- `submit_activity_screenshot` 与 `generate_monthly_evaluation` 的超时均为 60 秒。
- 公积金历史总账余额为 `-257.00` 元，旧汇总结转记录为 `superseded`。
